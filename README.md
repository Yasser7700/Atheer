## Technology Stack

- **HTML5** — semantic, RTL-native, fully accessible
- **CSS3** — custom properties, grid, flexbox, animations
- **Vanilla JavaScript** — IntersectionObserver, no dependencies
- **Fonts** — IBM Plex Sans Arabic + Inter (Google Fonts)
- **No frameworks, no build tools** — open `index.html` directly

---

## Features

- ✅ RTL Arabic primary language
- ✅ Scroll-triggered reveal animations
- ✅ Animated NFC wave rings (hero & demo)
- ✅ Interactive payment simulation (5-step flow)
- ✅ Animated token flow diagram
- ✅ Security visualization with rotating layer dots
- ✅ Animated number counters
- ✅ Magnetic button effects
- ✅ 3D card tilt on hover
- ✅ Sticky navbar with scroll transformation
- ✅ Mobile-responsive with hamburger menu
- ✅ `prefers-reduced-motion` support
- ✅ ARIA labels throughout
- ✅ Performant — no external JS libraries
